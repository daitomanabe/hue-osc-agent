# README.md

This folder contains the planning package for a headless OSC to Philips Hue local control engine.

Files:
- `AGENTS.md` project level orchestration and rules
- `TECHNICAL_DESIGN.md` architecture and implementation details
- `OSC_SPEC.md` OSC namespace and semantics
- `IMPLEMENTATION_PLAN.md` build phases and acceptance criteria
- `CONFIG.example.yaml` sample configuration

Recommended next step:
Implement the TypeScript skeleton exactly along the module boundaries defined in `AGENTS.md` and `TECHNICAL_DESIGN.md`.
